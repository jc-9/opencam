# Project: opencam_101126
- Area: COMPUTER_VISION
- Started: 2026-10-11
- Goal: Beautiful Omarchy-native tool for setting up USB webcam + C-mount lens: live view + switchable basic filters (threshold with histo, sobel) to visually aid focus/alignment.

## Stack / environment
- Python 3.x + venv (system-site-packages for PyQt6)
- PyQt6 6.11 (system), opencv-python-headless 5.0, numpy 2.5
- Linux V4L2 webcams (/dev/video*); prefers USB via v4l2-ctl names
- Runs as native Qt app under Hyprland (XWayland or wayland)

## How it works
- Main window: left vertical sidebar (toggle, Camera dropdown + explicit "Path: /dev/videoX", Add Filter combo + numbered applied-filters list with remove/up/down) + central live preview with numbered pipeline label above ("1:Gaussian → 2:Binary → 3:Sobel") + right dynamic filter panel (controls for the selected stage; panels restore saved params on reselect).
- Filters apply sequentially in worker (each stage's output feeds the next); histogram shows input of the selected binary stage.
- Binary Threshold: threshold spin (0-255) + live mini grayscale histogram with draggable red line.
- Sobel X: kernel size selector (3/5/7).
- Video: QThread + VideoCapture, filter chain in worker, QImage to custom VideoDisplay (aspect preserve).
- Camera: robust list_usb_cameras() with v4l2-ctl parsing + USB priority + always returns /dev path.
- Omarchy theme compat: load_omarchy_palette() reads active `omarchy theme current` + colors.toml, applies to QSS + QPalette. Falls back cleanly.
